
# COMPUTER PROGRAMMING ASSIGNMENT

**Student Registration Number:** HDB212-D1-0077/2026

## 1. Introduction

This repository contains the source code and project documentation for the Computer Programming Assignment.

The assignment covers arrays, structures and functions, pointers, and dynamic memory allocation using the C programming language.

## 2. Assignment Sections

### Section A: Arrays

This program:
- Accepts marks for 10 students.
- Calculates the average marks.
- Identifies the highest and lowest marks.
- Displays all marks above the average.

### Section B: Structures and Functions

This program uses a student structure containing:
- Admission Number
- Student Name
- Course
- Age
- CAT Marks

It captures and displays information for five students and calculates their average CAT marks.

### Section C: Pointers and Dynamic Memory Allocation

This program:
- Allocates memory for exactly 15 integers using malloc().
- Accepts 15 integer values.
- Calculates their total and average.
- Releases allocated memory using free().
